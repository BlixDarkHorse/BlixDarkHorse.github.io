# UNIVERSO BDH — Hub Central

Hub de branding con negro, rosa eléctrico, dorado, transparencias y arte protagonista.

## BLAZZAR ON READY
Todos los CTA de Entertainment apuntan a https://ent.universobdh.me

## OAuth
La interfaz incluye botones para Galaxy Manager Systems, Google y Microsoft. Son puntos de integración preparados. Deben sustituirse las URLs de `config.js` por los endpoints OAuth reales de producción. Nunca coloques client secrets en HTML/JS.

## WebView2
`main.py` usa pywebview con `gui='edgechromium'` y ventana frameless.

## Arte
El prototipo usa temporalmente la imagen indicada en el código original. Para producción, sirve las imágenes desde tu propio dominio o CDN para evitar depender de un tercero.
